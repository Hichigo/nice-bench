# nice-bench

Стенды замеров движка NICE для телефонов и планшетов: https://hichigo.github.io/nice-bench/

Каждый стенд — один HTML-файл без внешних зависимостей; в конце он показывает JSON и сохраняет его файлом.

| Файл | Что меряет |
|---|---|
| `graphics.html` | Графика: сцена плеебла, тени, свет, частицы, пост-обработка; набор «Нагрузка» |
| `frame.html` | Частота экрана до и после касания, лимитеры FPS, цена объектов, скорость JS |
| `anim.html` | Скиновые персонажи: 1–40 по 43 кости и 47 тыс. вершин |
| `assets.html` | base64 и base122, распаковка, meshopt, декод картинок |
| `audio-input.html` | Звук: разблокировка, форматы, беззвучный режим, сворачивание; ввод: мультитач, жесты |

Файлы собираются в основном репозитории движка (`bench/site/build-pages.mjs`); правки здесь затрутся следующей сборкой.
